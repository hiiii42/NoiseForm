# NOISEFORM 使用指南（用户文档）

> 对应版本 1.8.8。按"你想做什么"组织，每节给一个例子。开发者请看 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 0. 启动与两种模式

```
node server.js        # → http://localhost:8787
```

| 模式 | 怎么进入 | 效果 |
| --- | --- | --- |
| DEMO | 不填令牌 | 全部功能可用，输出是本地程序化"海报"，不花 Anlas，用来熟悉流程 |
| LIVE | 设置 → 填 NovelAI 持久令牌 | 真实生成，顶栏显示 Anlas 与 V5 免费额度 |
| LIVE（服务端令牌） | 启动时 `NAI_TOKEN=pst-… node server.js`，浏览器不填令牌 | 同上，请求只经本地代理；适合不想把令牌存进浏览器 |

连接方式默认自动（浏览器直连；直连失败时用本地代理 `server.js` 转发）。

## 1. 生成一张图

1. 左侧「提示词」里输入 tag：`1girl, silver hair, {{masterpiece}}, artist:wlop`。编辑器会高亮 `{加强}` `[减弱]` `1.2::权重::`，输入时弹出胶囊式补全（英文 + 中文 + 热度）：中文直接查（`红发` → `red hair`）；`=原神` 先选作品再选角色；`artist:wl` 只搜画师；`@名称` 插提示词块。编辑框底部中间的拖动条可以调整框的高度（双击恢复自动）。`↑/↓` 选、`Enter`/`Tab` 插入、`Esc` 关闭。在句子后面接着打（如 `…under the rain. smi`）只补全最后一个词。
2. 选尺寸：下拉预设，或拖「横 ↔ 竖」滑杆在 13 档 1M 以内的构图里选（读数实时显示，骰子按钮随机一档）；再选张数、步数 / CFG / 采样器；种子留空 = 随机。
3. `Ctrl+Enter` 或点「生成」。舞台变成一片数据点阵：准星先锁定一个和图片同比例的框，随进度放大（右上读数 ×1 → ×5），图在框里显影后直接变成正常看图，同时进入右侧档案。开了「过程显示」（流式预览）时，进度只跟服务器的真实步数走：排队时显示「··」和「等待首帧」，不会先估一个数再往回跳。生成时点开别的图不会被打断（点档案顶部的进度卡片回到进度画面）。设置 →「显影动画」可关掉落点动画。

常用：`Ctrl+↑/↓` 给光标处 tag 调权重（`1.1::tag::` 形式，0.1 一档，可降到负数如 `-0.5::glasses::` 把元素推开）；`Ctrl+←/→` 把 tag 前后挪一位；「随机提示词」；质量标签与负面预设和官方前端一致。

**整理长提示词**：行首 `#` 是注释（`Ctrl+/` 切换整行），单独一行 `---` 是分割线，生成时都会被去掉；点注释行左边的 ▾ 可以把它下面那段 tag 折叠起来只看标题。粘贴的内容原样插入（圆括号是 tag 的一部分，如 `sunna_(zenless_zone_zero)`，不会被当成权重）；离开编辑框时下划线换空格、全角逗号换英文、段尾补逗号（设置里可关）。鼠标停在 `artist:名字` 上会显示 nax.moe 的社区样图。

例：
```
# 画师
artist:wlop, 1.2::artist:ningen mame::
---
# 主体
1girl, silver hair, smile
```

**免费判定**：V5 Opus 用户在 ≤1MP、≤28 步、1 张、无精确参考且额度未用完时生成免费，面板费用会显示 0。

## 2. 多角色、图生图、局部重绘、参考

- **角色**（V4+）：「角色」区每人独立正 / 负面，「AI 决定位置」或手动位置。
  - **V5 自由站位**：点角色卡上的位置按钮 → 舞台上出现编号圆点，拖到想要的位置（或先点上方「C2 1boy」选人，再点画面）；方向键微调，Shift 加大步长；「完成」/ Esc 退出。按钮显示坐标，如 `28·41`。
  - **V4.x**：5×5 位置格（A1–E5）。
- **图生图**：把图拖进页面或在档案里「设为底图」，调强度 / 噪声。
- **局部重绘**：「重绘」打开蒙版画笔（`[ ]` 调笔刷、`Shift` 擦除、`Ctrl+Z` 撤销）。
- **氛围迁移 Vibe**：多图、信息提取、强度；V4+ 首次编码 2 Anlas，之后缓存。
- **精确参考**（V4.5）：角色 / 画风 / 两者，强度与保真度。
- V5 不支持氛围 / 精确参考：这两个分区会置灰（标「此模型不支持」）；切到 V4.5 才能添加。已添加的参考在 V5 下仍可删除，若保留则这次生成按官方行为改用 V4.5。

## 3. 看图、比图、管理档案

- 看图：滚轮或 Ctrl+滚轮缩放（以光标为中心，放大后可铺满整个舞台，不受原图框限制；顶部信息和工具栏保持在最上层）、放大后拖动；右上角「↺ 百分比」按钮、双击或 Esc 回到初始大小。
- 舞台工具栏：下载、复制、放大 4×、变体、增强、导演工具（去背景 / 线稿 / 素描 / 上色 / 表情 / 净化，带 A/B）、设为底图 / 重绘 / 氛围 / 参考、复用种子 / 全部参数；更多的在「更多」菜单。图生图 / 重绘 / 增强 / 后处理 / 分块放大的结果多一个「原图」按钮：**按住**看来源图（长按图片本身也行）。
- 档案缩略图悬停时右下角有两个小钮：只用这张的**种子** / 只套用**参数**（不切换图、种子不变）。
- **标记**：`F` 收藏、`X` 淘汰（自动跳下一张）、`U` 清除。`←/→` 按当前筛选结果翻页。
- **筛选**：全部 / 收藏 / 未收藏 / 已保存 / 未保存 / 已淘汰 × 今天 / 昨天 / 7 天 / 30 天 / 某天。
- **搜索**（空格分隔，同时满足）：
  - 例：`artist:wlop "long hair" -glasses model:v5 size:832x1216 date:7d is:star`
  - 中文词自动转英文 tag：`红发`；`seed:123` `steps:28` `cfg:5` `uc:xxx` `no:42` `job:7`（某个队列批量的图）；点搜索框旁 `?` 看全部。
- **右键菜单**：右键一张档案图 → 查看 / 只用种子 / 套用参数（不含种子）/ 加入对比 / 收藏 / 淘汰 / 下载 / 删除。
- **快速取用**：`Alt+左键` 锁定这张图的种子（再按一次解锁，回到随机）；`Alt+右键` 套用它的参数但保留当前种子（适合「同种子换提示词」或「同提示词换种子」的比对）。
- **多选 / 批量**：`Ctrl+点击` 逐张选、`Shift+点击` 连选、`Ctrl+A` 全选当前筛选结果；选中后在任意一张选中的图上**右键**：收藏 / 淘汰 / 加入对比 / 导出 ZIP / 标记已保存 / 删除。档案顶部只显示「已选 N」，`Esc` 取消。
- **对比**：工具栏「对比」或右键「加入对比」：2–4 张同步缩放，或 A/B 滑动；下方列出 tag 增删（带中文）和参数差异；「末位跟随最新」让最后一格自动换成新图。
- **网格档案**：档案栏标题右侧按钮展开成网格，拖左边缘调宽、底部滑块调缩略图大小。
- **保存**：设置里选保存文件夹（Chrome / Edge）后可直接写入、检测文件是否还在；可开自动保存。已保存的图显示 ✓，重复下载会提醒。文件名形如 `0042_1girl-smile_123456_<记录id>.png`，末尾的记录 id 保证不同的图不会同名（以前保存过的图仍按原文件名识别）。
- **待保存**：极少数情况下图已经生成、但浏览器存储写不进去（例如空间满了）。这时图不会丢、也不会重新生成（不再花钱）：顶栏出现「待保存 N」，点开可「重试保存」或「下载」；队列会暂停，清出空间后点「继续队列」只重试保存。注意待保存的图只在当前页面里，刷新或关闭前请先处理。
- **存储**：档案栏底部显示占用，点开可清理"已保存且未收藏的旧图"、删除淘汰图、申请持久存储。

## 4. 生成时不干等：自动生成与队列

**连续模式**（默认）：按「自动生成」（`Ctrl+Shift+Enter`，或**长按**大生成按钮），当前参数被冻结成一个**批量**进队列，编辑区变成草稿——你可以边跑边改 tag。

- 改了之后提示词上方出现差异条：**下一张起应用** / **跑完再排队** / **还原**。
- 跑的时候按「生成」= 用编辑区**插队**一张。
- 「队列」按钮：排序、载入、结束 / 移除；刷新页面后队列保留（暂停）。如果刷新时正有一张在生成，这个批量会标成「结果未知」：先看档案和 Anlas 再决定继续，继续不会自动重发那一张。**历史**页记录每个跑完的批量（时间、张数、种子、与上一批的提示词差异），可「载入」「同种子排队」「看图」。
- **同种子**（链条按钮）：新批量第 N 张沿用上一批第 N 张的种子，适合比较改动；种子栏填了固定种子时以固定为准。
- **重复检测**：下一张和档案里某张图参数、种子完全一样时，队列会在生成前暂停并告诉你和哪张一样（例如种子锁定的批量、或「同种子」但忘了改提示词）。改了再「继续时应用」；确实要重复就直接「继续队列」。
- 开着「仅免费」时每张开始前按该批量的参数检查，不满足就暂停并说明原因；关掉「仅免费」再点「继续队列」就用 Anlas 接着跑。暂停期间改了提示词，差异条会提示「继续时应用 / 跑完再排队 / 还原」。

**改动后模式**：停手约 1 秒自动生成一张，边改边看。

例：先跑 `1girl, red hair, smile` 10 张；跑到第 3 张觉得要加 `looking at viewer`，直接改——差异条出现，点「下一张起应用」。

## 5. 种子

- `S` 或工具栏「种子」把当前图的种子填进种子栏，旁边显示来源（如 №0041）；尺寸 / 模型不同时会提醒构图会变。
- **重复提醒**：固定种子、参数和上一张完全一样时再点「生成」会先提示；3 秒内再点一次 = 清除种子继续。
- **导入**外部 NovelAI 图（拖入 / 粘贴 / 顶栏「导入图像」）：先选「图生图」或「局部重绘」；下方按需勾选 提示词 / 负面 / 角色 / 设置 / 种子 后「导入元数据」（只勾种子 = 只拿种子；勾设置 + 种子 = 拿构图）。「参数免费化」把尺寸缩到 1M 内、步数 ≤28、1 张；「查看元数据」看原始 JSON。

## 6. X/Y 对比网格

提示词标题栏的「X/Y」按钮。固定种子，**直接在提示词上点 tag** 设变量：

| 想比什么 | 怎么设 |
| --- | --- |
| 画师权重 | 点 `artist:wlop` → 权重 0.6 / 0.9 / 1.2 |
| 这个 tag 有没有用 | 点 tag → 有 / 无（真的删掉），再加种子轴 × 2 |
| 步数 / CFG / 重缩放 / 采样器 / 种子 | 加参数轴 |
| A 画师 vs B 画师 | 点 tag → 替换为多个值 |

开始前预览每一格的实际提示词和费用；网格作为一个任务进队列。结果格子可「采用」（参数 + 种子载入编辑区）、「对比」、在档案打开；可导出成一张 PNG。

## 7. 审阅栏：中文翻译 / 拼写检查

提示词标题栏「译」「检」各自开关，「⇤/⇥」收起 / 展开。

- 翻译：每行每个 tag 的中文（本地 11 万词库，圆点颜色 = 分类），自然语言句子在线机翻。
- 拼写：词库和 NovelAI 词表都没有的 tag 画红波浪线，审阅栏给最接近写法，点击替换；旧写法画橙色虚线并提示规范 tag。
- 悬停审阅栏高亮原文位置，点击选中；收起后仍用红 / 橙点标出问题行。

## 8. AI 构思（提需求 / 修改提示词 / 改角色 / 看图优化 / 搭画师）

设置 → 「AI 构思」：填地址和 key → 点「获取模型」→ 从下拉里选一个（例：地址 `https://api.deepseek.com`，选 `deepseek-flash`）。「深度思考」默认关：转 tag 用不到，关掉快很多，也不会把输出截断。提示词标题栏「AI」：

- **提需求**：写新画面或想怎么改。有提示词时默认「修改当前」，例：当前是纽约街头三人跳舞，输入「换成农村场景」→
  - 删除：~~times square~~ ~~city lights~~ ~~crowd~~ …（默认勾选，点一下保留）
  - 替换：`night → day`、`The three teenagers dance … crowded plaza → … on a dirt path between rice paddies`（原地替换，`1.2::night::` 这类权重保留）
  - 新增：`rural` `rice paddy` `blue sky` …（按类别）
  - 点「应用：删 6 · 换 2 · 加 6」写回编辑框（可撤销）。改的是基础提示词和角色提示词里所有出现的地方；新增放在末尾画师行之前。
- 选「重新写」= 按描述生成一整套新提示词：替换基础提示词，也替换角色——多人时可拆进角色提示词，否则清空原有角色（预览里会提示「将清除现有 N 个角色」，可撤销）。
- 每个 tag 都经本地词库 + NovelAI 词表校验：旧写法自动换规范写法，查不到的标 "?" 默认不选，冷门标黄。顶部一排显示覆盖度（主体 / 外貌 / 服装 / 表情 / 动作 / 构图 / 背景 / 光照）。
- **附带当前图片**（舞台上有图时出现）：把这张图一起发给支持识图的模型。需求留空 = 「对照这张图优化提示词：保留原意，修正没画出来或画错的地方」——提示词是原意，模型只建议补强被忽略的元素、替换被误解的 tag，不会把提示词改成描述这张图。模型不支持图片时会提示换模型或关掉开关。
- **改角色**：修改 / 检查时模型能按角色给建议，按角色分组显示，每项可单独开关。例：三人跳舞图（附图），输入「删掉图中的男人」→
  - 删除：~~1boy~~（基础提示词里的人数，`2girls` 保留）
  - 角色 2 · 1boy：~~删除角色~~
  - 输入「把粉发女孩放到左边，金发女孩放到右边」→ 角色 1「位置 → 25·43」、角色 2「位置 → 75·41」，句子里的 three 改成 two。应用位置后「AI 决定位置」自动关闭；新增角色超过模型上限（V5 32 / V4.x 6）时略过并提示。
- 「检查当前提示词」：列出缺什么、哪里冲突，建议删 / 换的项同样可以勾选后直接应用。
- **搭画师**：写想要的画风（可留空、可附图），例「厚涂、柔和的光影」→ `artist:ciloranko` `artist:as109` …。悬停画师看 nax.moe 样图；点一下取消不要的。不满意写反馈「饱和度低一点，更像水彩」点「再调」，模型会记得前几轮和你去掉了谁（关掉对话框再打开也在，「重新开始」清空）。「应用画师」只替换提示词里的画师，其他不动。

## 9. 提示词块与提示词历史

- **提示词块**（提示词下方「提示词块」）：把画师串 / 质量串 / 服装组合存成块（名称 + 内容），在提示词里写 `@名称` 引用，编辑器显示为胶囊，悬停看内容；生成时自动展开（档案里保存的是展开后的提示词）。面板里可新增 / 插入 / 删除、导入导出 JSON；先选中一段文字再打开面板 = 直接存为块。旧的片段会自动迁移。面板为空时可点「添加示例」放回几条示例（V5质量、水手服、画师串、雨夜城市）。
  - 例：块「水手服」= `serafuku, pleated skirt, red neckerchief`，提示词写 `1girl, @水手服, smile`。
- **历史**：每次生成记录提示词版本，连续相同自动合并；列出相对上一版的 tag 增删（带中文）、张数、缩略图；「恢复此版本」一键写回。

## 10. 后处理工作台

舞台工具栏「更多 → 后处理」进入**原位模式**：左栏变成四页签（调色 / 风格 / 细节 / 修饰），中间原位实时预览（WebGL，拖滑杆不卡），右侧档案照常——点别的图就处理那张；「← 结束处理」退出。

- **控件**：拖滑杆实时看；点右侧数值直接输入；双击标签复位单项；分组标题悬停有「对比 / 复位」；页签右上角圆点 = 这页有改动。顶部工具条：按住看原图（或按空格）、撤销 / 重做（`Ctrl+Z` / `Ctrl+Shift+Z`）、全部复位。
- **调色**：曝光 / 亮度 / 对比 / 高光 / 阴影 / 白色 / 黑色；色温 / 色调 / 色相 / 自然饱和 / 饱和；RGB 与分通道曲线（点击加点、拖动、双击删点）；HSL 8 色带；色调分级（阴影 / 中间调 / 高光 / 整体 + 混合 / 平衡）。
- **风格**：仿制色调（拖入参考图，只记颜色统计不存图，强度可调）；.cube LUT（强度可调）。
- **细节**：锐化（数量 / 半径 / 阈值）、清晰度 / 纹理 / 去朦胧、暗角（数量 / 中点 / 羽化 / 圆度）、颗粒、色散（径向 / 线性，中心可在图上点）。
- **修饰**：马赛克画笔（涂抹 / 擦除、大小 / 硬度、像素块或模糊、撤回一笔 / 清除；笔迹只属于这张图）、文字水印（九宫格位置、大小按图宽比例、不透明度、颜色）、元数据保留（所有参数 / 仅后处理 / 无）。
- **预设**：底部「存为预设」→ 就地起名保存；预设区点名字载入（可撤销）、改名、删除。马赛克笔迹和水印文字不进预设。
- **导出**：生成一条新的档案记录（原图不动，记录里带后处理参数和来源图）；留在模式内可继续。

## 11. 分块放大（免费出大图）

舞台「更多 → 分块放大」：把图拆成几块 ≤1M 像素的区域，每块用编辑区的提示词做一次 img2img（走队列，Opus 免费档内 0 Anlas），再拼回一张更大的图。对话框里能看到网格、块数和费用；倍数默认「自动 1.3×」，想改重绘幅度 / 噪声 / 重叠点「显示高级」。结果是一条 `UPSCALE` 记录；中间块默认不在档案里显示（搜索 `is:tile` 可看）。

## 15. 常见问题

- **生成报 403 / 免费标识消失**：NovelAI 对该账号关闭了免费生成；面板不再显示 FREE，按正常 Anlas 计费。
- **连不上 NovelAI**：设置里切「本地代理」；需要翻墙时打开「设置 → 上游代理」，填你代理软件的地址和端口（默认 `127.0.0.1:7890`，按自己的软件改）。也可以用启动参数 `NF_UPSTREAM_PROXY=http://host:port`。本地服务只接受本机访问，局域网其他设备打不开代理是预期行为。
- **`S` `F` `X` `U` 没反应**：光标还在提示词编辑框里时，这些键是在打字。按 `Esc` 离开编辑框，或点一下舞台 / 档案再按；中文输入法开着也能用。
- **反馈问题时**：「设置 → 导出诊断日志」下载一个 JSON，记录最近约 200 个请求走的线路、多久收到响应头 / 首帧、怎么结束的，以及本地代理的日志。只有这些元数据，没有令牌、提示词和图片，可以放心发出来。
- **生成卡在 93% 左右不动**：进度条在请求发出后按预计时间走，到 93% 左右停住等服务器。超过预计时间后舞台会显示「等待服务器 1:23」，说明还在等。服务器 4 分钟不回应、或者图传到一半停了 2 分钟，会自动结束并提示「结果未知」（不会自动重发，先看档案和 Anlas）。打开页面时如果提示「本地服务还是旧版本」，请关掉运行 `node server.js` 的窗口再重新启动：页面文件每次刷新都是新的，但服务只在启动时读一次代码。
- **提示「结果未知」**：请求已经发出后连接断了（直连或经本地代理都一样），NovelAI 可能已经生成并扣费，所以不会自动重发。先看顶栏 Anlas 是否变化、档案里有没有新图，再决定是否手动重试；队列此时会暂停。
- **导入图片提示「已忽略 N 个无效字段」**：这张图的元数据里有超出范围或格式不对的值，已跳过，其余参数正常导入。
- **AI 构思「当前模型不支持识图」**：换支持图片的模型，或关掉「附带当前图片」。
- **AI 构思失败**：先在设置里「获取模型」看能否连通；提示「输出被截断」时关掉「深度思考」或换模型；流式长连接经上游代理可能断，改「直连」。
- **档案太大**：存储面板清理；1.5 GB 以上会提醒一次。
